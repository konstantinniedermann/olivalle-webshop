# Olivalle Webshop

**Biologisches Olivenöl aus Andalusien, Spanien — direkt in die Schweiz.**

Olivalle ist ein kleiner, feiner Online-Shop für hochwertiges Bio-Olivenöl eines Schweizer Einzelunternehmers. Ziel ist es, den bestehenden manuellen Bestellprozess durch einen modernen, vollautomatisierten Webshop zu ersetzen — mit Bezahlung via Twint oder Kreditkarte, automatischer Rechnungsstellung und der Möglichkeit für wiederkehrende Lieferungen.
