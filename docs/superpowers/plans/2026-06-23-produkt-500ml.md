# Produkt „Olivenöl 500ml" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das neue Premium-Gebinde „Olivenöl 500ml" (CHF 25, Geschenkflasche) im datengetriebenen Webshop ergänzen.

**Architecture:** Neue Produktzeile im idempotenten Seed (`001_initial.sql`) → erscheint automatisch in Shop, Warenkorb, Stripe, QR-Rechnung und Mails. Optimiertes Produktbild als statisches Asset. AGB-Preistabelle gegen Drift robust gemacht.

**Tech Stack:** SQLite (Seed/Migration), FastAPI + Jinja2, pytest, macOS `sips` für Bildoptimierung.

## Global Constraints

- Schweizer Konvention: kein „ß", immer „ss"; Preise in CHF.
- UPSERT-Regel (Bug #137): admin-editierbare Spalten (`aktionspreis_chf`, `aktionstext`, `aktion_von`, `aktion_bis`) NIE im `ON CONFLICT … DO UPDATE` auflisten.
- Produktbild-Namensschema: `products/olivalle-<menge>.jpeg`, max. 1080 px lange Kante, ~50–150 KB.
- Commit-Konvention: `feat:` / `fix:` / `docs:` / `test:`; Footer `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.
- Produkttext verbatim vom SH (siehe Task 2).
